# 管理画面の使い方

設置先の `/admin/login` からログインします。サブディレクトリに設置した場合は、そのパスに続けて指定します。

## 担当者の権限

| 権限 | 使用できる機能 |
| --- | --- |
| 閲覧者 | フォーム一覧、全フォームの受信履歴・CSV・非公開添付、配信状況の閲覧 |
| 編集者 | 閲覧者の機能に加え、フォーム・共通項目の作成・編集、公開・公開停止、複製 |
| 管理者 | 上記のすべて、利用者・権限とテーマの管理、フォーム保管・復元、受信履歴の削除 |

利用者は「利用者管理」で追加します。管理者が権限を変更した利用者は、次の管理画面操作時にログインし直します。最後の管理者は別の権限に変更できません。

## フォームを作成する

1. 「フォーム作成」で「お問い合わせ」「イベント申し込み」「アンケート」から、用途に近いひな形を選びます。
2. 名前と公開パスを入力します。例えば `contact` なら設置先の `/contact`、空欄なら設置先のトップが公開URLです。
3. 「入力項目」で利用中の項目を編集します。「追加する項目」から標準項目・登録済みの共通項目・新規項目を選び、「項目を追加」を押します。↑ ↓ で並べ替えられます。
4. 必須、選択肢、入力制限、再入力の照合先、エラー文言、許可ファイル形式・容量を必要に応じて設定します。「項目一覧・登録」で共通項目を用意すると複数フォームにコピーできます。
5. 「通知メール」で通知先と件名、本文に含める情報を設定します。複数の宛先は半角カンマで区切ります。自動返信先には項目キー `email` を使います。ひな形に含まれるサンプルの社名や案内文をご利用の内容に変更してください。
6. 「下書きを保存」してから「保存済みの内容を公開」を押します。公開中に編集した場合も、再度公開するまで利用者には直前の公開版が表示されます。別の担当者が先に保存した場合は、画面を開き直して最新の内容を確認します。

reCAPTCHA v3 を有効にする場合は、サーバー側の `RECAPTCHA_SITE_KEY` と `RECAPTCHA_SECRET` を設定します。移行したフォームに公開を妨げる項目がある場合は編集画面に理由を表示します。従来の受付条件を維持できているかを確認してから公開してください。

「フォーム一覧」の「複製」で、設定と入力項目を引き継いだ下書きを作成します。元のフォームに届いた回答は元の受付に紐づきます。

## 受信履歴とCSV

「受信履歴」でフォームを選んで「表示」を押すと、CSVをダウンロードできます。CSVはUTF-8 BOM付き、行区切りはCRLFです。日時を先頭に、受付時点の項目名を使います。新しい受付から順に列を決め、後から見つかった過去の項目を末尾に追加します。複数選択は改行しない空白で区切ります。添付ファイルは受付詳細から取得します。表計算ソフトが数式として扱う先頭文字には、単一引用符を付けます。

「回答を受信履歴に保存する」を外したフォームは、履歴・CSVに表示しません。配信自体の経過は「配信状況」で確認できます。結果不明のメールはSMTPサーバーの記録を確認して扱いを決めます。

## 公開を止める・保管する・削除する

- **公開停止**　フォーム編集の「公開設定」で停止します。回答と配信を保持し、再公開できます。
- **フォームの保管**　公開停止後、管理者が「フォームを保管する」を開き、名前を確認して保管します。保管中も公開パスは予約され、受信履歴と配信は維持されます。「フォーム一覧 → 保管済み → 下書きに戻す」で復元できます。
- **受信履歴の削除**　管理者が受付詳細で対象の受付番号を確認して削除します。対象の回答と非公開添付を消去し、二重送信を防ぐため受付キーと配信状況を残します。関連メールに送信待ち・送信中・送信失敗・結果不明がある場合は、先に配信結果を確定します。ストレージ障害時は履歴を閲覧対象から直ちに外し、定期処理で添付削除を再試行します。削除した回答や添付は管理画面から復元できません。

旧EasyMailから取り込んだ独自テーマの差分、素材の差し替え、プレビュー、公開の操作は[独自テーマの照合手順](IMPORT.md#custom-themes)にあります。
