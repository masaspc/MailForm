# 通常の ChatGPT で移行の案内を受ける

公開リポジトリの手順と、ご自身の作業結果で進められます。新しいチャットに、次の文をそのまま貼ってください。

> 旧 EasyMail のフォーム・履歴・添付を、今と同じ公開URLで MailForm に移行したいです。これから新サーバーを1台用意します。移行先は AlmaLinux 10.3 Minimal と MariaDB です。旧版の番号はこれから確認します。プラグイン移行は不要です。
>
> https://github.com/masaspc/MailForm/blob/main/docs/ALMALINUX10.md を開き、この手順に沿って日本語で案内してください。毎回「どこで操作するか（手元のPC・旧サーバー・新サーバー）」「次に行う操作を1つ」「成功の目印」を示し、私が結果を返してから次へ進んでください。旧サイトは練習中も受付を続け、最終取込と照合の後に公開先を切り替えます。まずサーバーを用意するところからお願いします。

**GitHub の本文を読み取れないとき**は、[手順書のテキスト版](https://raw.githubusercontent.com/masaspc/MailForm/main/docs/ALMALINUX10.md)を開き、現在の節をチャットに貼ります。手順書をダウンロードして、ファイル添付が使えるチャットに渡すこともできます。

**途中で別のチャットに移るとき**は、終えたところから再開できます。たとえば旧版が 2.00.125 で新サーバーに Git のコピーがあれば、「旧版は 2.00.125、管理入口は `/admin`、新サーバーで `git clone` まで完了し、簡単設置はこれから」と伝えます。[2.00.125 と 2.00.124 の直接移行](IMPORT.md#easymail-200125)

- 最後に成功した操作と、次にしたいこと。例「新サーバーの練習用管理画面にログインできた。次は旧データのコピーを取りたい」。
- 旧 EasyMail の版番号と、新サーバーで使った MailForm の版。取得したフォルダーで `git rev-parse HEAD` を実行するとコミット番号が分かります。GitHub の手順書 URL の `main` をその番号に替えると、設置した版の手順を参照できます。
- 止まった場合は、どの端末でどのコマンドを実行したか、エラーの該当行。パスワード、SSH 秘密鍵、`APP_KEY`、`.env`、DB ダンプ、実際の問い合わせ本文・添付はサーバー側に保管し、チャットには個人情報や認証情報を伏せた結果だけを貼ってください。

旧管理画面の場所と対応版は[旧サイトの確認](EASYMAIL-VERSION.md)、コピーの準備は[旧データの取込](IMPORT.md)、公開先の切替と切り戻しは[移行当日の手順](CUTOVER.md)で確認できます。
